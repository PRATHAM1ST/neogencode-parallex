This page is a small experiment in doing more with less. Just an image, HTML, and a few lines of CSS for the effect.

Peek behind the scroll +
.parallax {
  position: relative;
  isolation: isolate;
  clip-path: inset(0);
}
.parallax::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  background: url("assets/mountains.jpg") center / cover;
}
@media (prefers-reduced-motion: reduce) {
  .parallax::before { position: absolute; }
}

A fixed image layer stays behind the content, clipped to its section as you scroll. It works on desktop and touch devices using only HTML and CSS. With reduced motion enabled, the layer moves with the section instead.
